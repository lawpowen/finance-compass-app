# Finance Compass 决策记录

## 2026-07-27：模板对话框自行管理输入生命周期

- 背景：创建模板后退出对话框会访问已销毁的 `TextEditingController`。
- 决定：移除外部控制器，让对话框内部管理输入状态。
- 理由：避免异步关闭期间的生命周期竞态。
- 替代方案：延迟释放外部控制器；否决，仍容易受导航时序影响。
- 影响：模板创建恢复稳定，相关回归测试通过。
- 来源：`019f824f-a75f-7b11-b754-7cd56566d1b0`

## 长期业务决定：交易口径分离

- `planned` 是预计值；`actual/settled` 是已发生值。
- 余额、预算、趋势和报告必须明确是否包含预计交易。
- 负债账户余额可以为负。
- AI Gateway 保持只读。
- 来源：项目源码与 Finance Compass 工程文档；聊天 `019f824f-a75f-7b11-b754-7cd56566d1b0`

## 2026-07-28：远端认证异常时停止同步

- 决定：发现 remote URL 含凭据后，不 fetch、不 push、不覆盖远端。
- 理由：避免凭据进一步传播和错误认证操作。
- 下一步：轮换凭据，将 remote URL 改为无凭据 HTTPS 或 SSH。
