# 安全与运维

## 当前安全模型

- 财务资料默认只存放在应用文档目录的 SQLite 数据库。
- 当前没有用户认证、远程同步或后台遥测。
- AI 网关和系统分享是用户主动触发的外部数据流。
- 完整 JSON 可能包含敏感财务资料，用户应自行保护导出文件。
- 导入与导出只在用户主动选择文件或保存位置后执行；应用不申请后台云上传，也不自动发送完整备份给外部 AI。

## 升级与故障恢复

- v7 升级前必须成功创建恢复点。
- 数据库升级和完整导入使用事务。
- 完整导入前验证文件非空、格式版本、字段类型、ID 唯一性及实体引用，再在应用私有文档目录生成 JSON 恢复点；事务提交前执行 SQLite 完整性与外键检查。导入失败时保留原数据库状态并显示可读错误。
- Android 导出使用系统文档选择器直接写入并关闭输出流；应用只在字节非空且原生写入没有抛错时报告成功。取消保存不产生成功提示，旧的 0 KB 文件不会被当作可恢复备份。
- 启动后执行 SQLite 完整性与外键检查。
- 恢复原始数据库时，应用必须停止，并同时处理 SQLite、WAL 和 SHM 文件。
- 手工账单对账前必须停止当前应用并使用 SQLite 在线备份接口生成一致性副本；修复应写入明确交易、重算物化余额并执行 `integrity_check` 与 `foreign_key_check`，不得只覆盖账户余额掩盖缺失流水。

## Google Play 与身份计划

Android 包版本为 `0.8.0+25`。正式版应用 ID 为 `com.financecompass.app`；内部测试 Debug 版使用 `com.financecompass.app.debug` 和独立数据目录，避免覆盖正式版。Debug APK 使用开发签名，只用于设备测试，不得提交 Google Play。Google 登录、隐私政策、数据安全表和正式签名属于上架前工作，当前尚未实现或配置。未来认证不得改变本地优先默认值。

每次完成任务后的默认交付作业见[测试版发布与数据恢复作业](RELEASE_WORKFLOW.md)：导出可恢复的完整 v3 JSON、构建独立 Debug APK，并优先把这两项写入本机 `G:\我的云端硬盘\Finance Compass APK` 同步目录；EXE、临时 SQLite 和银行来源资料不在默认上传范围。

外部 AI 分析只在用户主动按下分享按钮后发送提示词；应用不会自动附加完整备份。提示词兼容分析摘要 JSON 与完整备份 JSON，并要求接收方严格区分已发生、未来已确定和预计记录。完整 JSON 仍可能包含账户名称、商户、备注和金额，用户必须在外部 AI App 中自行决定是否上传；提示词优化不改变这一敏感数据边界。
