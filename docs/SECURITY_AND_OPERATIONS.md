# 安全与运维

## 当前安全模型

- 财务资料默认只存放在应用文档目录的 SQLite 数据库。
- 当前没有用户认证、远程同步或后台遥测。
- AI 网关和系统分享是用户主动触发的外部数据流。
- 完整 JSON 可能包含敏感财务资料，用户应自行保护导出文件。
- 导入与导出只在用户主动选择文件或保存位置后执行；应用不申请后台云上传，也不自动发送完整备份给外部 AI。

## 升级与故障恢复

- v7 升级前必须成功创建恢复点。
- 数据库升级和完整导入使用事务。
- 完整导入前在应用私有文档目录生成 JSON 恢复点；导入失败时保留原数据库状态。
- 启动后执行 SQLite 完整性与外键检查。
- 恢复原始数据库时，应用必须停止，并同时处理 SQLite、WAL 和 SHM 文件。
- 手工账单对账前必须停止当前应用并使用 SQLite 在线备份接口生成一致性副本；修复应写入明确交易、重算物化余额并执行 `integrity_check` 与 `foreign_key_check`，不得只覆盖账户余额掩盖缺失流水。

## Google Play 与身份计划

Android 包版本为 `0.8.0+24`。正式版应用 ID 为 `com.financecompass.app`；内部测试 Debug 版使用 `com.financecompass.app.debug` 和独立数据目录，避免覆盖正式版。Debug APK 使用开发签名，只用于设备测试，不得提交 Google Play。Google 登录、隐私政策、数据安全表和正式签名属于上架前工作，当前尚未实现或配置。未来认证不得改变本地优先默认值。
