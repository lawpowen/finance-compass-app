系统通知使用部署版 Web/PWA，并由用户在各设备主动开启。默认按订阅设备时区 09:00 检查当天的提醒。iPhone 与 iPad 须先将网站添加到主屏幕，再打开该网页应用并允许通知。

独立审核使用 GPT-6.2-sol xhigh。修复了短账期提前提醒缺失、重新认证时的推送账号隔离、选中颜色对比及排程重复读取大账本问题。测试环境的浏览器自动授予通知权限未获批准，因此真机的系统通知由用户主动授权后验收。
